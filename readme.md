# Password Manager

A simple terminal application to store, search, and generate passwords.

## How to Run

### Interactive Menu
```bash
./passman
```

### Quick Commands
```bash
./passman generate 20
./passman list
./passman search github
./passman add
./passman delete discord.com
```

## Features

- Store credentials (website, username, password, notes)
- Search saved credentials
- Random password generator
- Master password protection
- Encrypted storage
